# Deployment Guide / Dağıtım Kılavuzu

## Render'da Deployment

### Adım 1: HubSpot API Token Oluşturma

1. HubSpot hesabınıza giriş yapın: https://app.hubspot.com
2. Sağ üst köşedeki ayarlar ikonuna tıklayın
3. **Integrations** > **Private Apps** bölümüne gidin
4. **Create private app** butonuna tıklayın
5. Uygulamanıza bir isim verin (örn: "Contact Tagging Service")
6. **Scopes** sekmesinde aşağıdaki izinleri verin:
   - `crm.objects.contacts.read` - Kontakları okumak için
   - `crm.objects.contacts.write` - Kontakları güncellemek için
7. **Create app** butonuna tıklayın
8. **Show token** diyerek access token'ı kopyalayın
9. Bu token'ı güvenli bir yerde saklayın

### Adım 2: OpenAI API Key Oluşturma

1. OpenAI platformuna gidin: https://platform.openai.com
2. Hesabınıza giriş yapın
3. Sağ üst köşeden **API Keys** bölümüne gidin
4. **Create new secret key** butonuna tıklayın
5. Key'e bir isim verin (örn: "HubSpot Tagging")
6. Key'i kopyalayın ve güvenli bir yerde saklayın
7. **Not:** Bu key yalnızca bir kez gösterilir, kopyalamayı unutmayın!

### Adım 3: HubSpot'ta Custom Property Oluşturma

Etiketleri saklamak için HubSpot'ta custom bir property oluşturmanız gerekiyor:

1. HubSpot'ta **Settings** > **Properties** bölümüne gidin
2. **Contact properties** sekmesini seçin
3. **Create property** butonuna tıklayın
4. Aşağıdaki bilgileri girin:
   - **Label**: AI Generated Tags
   - **Property name**: `ai_generated_tags`
   - **Field type**: Multiple checkboxes veya Single-line text
   - **Description**: "Tags generated by AI based on contact features"
5. **Create** butonuna tıklayın

### Adım 4: Render'da Web Service Oluşturma

1. Render hesabınıza giriş yapın: https://render.com
2. Dashboard'da **New +** > **Web Service** seçin
3. **Build and deploy from a Git repository** seçeneğini seçin
4. GitHub repository'nizi bağlayın (eyildirim-code/Hubppot-hcwhy)
5. Repository'yi seçin ve **Connect** butonuna tıklayın

### Adım 5: Web Service Konfigürasyonu

Render otomatik olarak `render.yaml` dosyasını okuyacaktır. Manuel konfigürasyon için:

**Basic Settings:**
- **Name**: hubspot-contact-tagging (veya istediğiniz bir isim)
- **Region**: Oregon (veya size yakın bir bölge)
- **Branch**: main (veya copilot/update-hubspot-api-contacts)
- **Root Directory**: Boş bırakın
- **Environment**: Node
- **Build Command**: `npm install`
- **Start Command**: `npm start`

**Advanced Settings:**
- **Health Check Path**: `/health`
- **Auto-Deploy**: Yes (otomatik deployment için)

### Adım 6: Environment Variables Ekleme

**Environment** sekmesinde aşağıdaki değişkenleri ekleyin:

| Key | Value | Açıklama |
|-----|-------|----------|
| `NODE_ENV` | `production` | Ortam tipi |
| `PORT` | `10000` | Render otomatik atayacak |
| `HUBSPOT_ACCESS_TOKEN` | `your_token_here` | Adım 1'de aldığınız token |
| `OPENAI_API_KEY` | `your_key_here` | Adım 2'de aldığınız key |
| `CRON_SCHEDULE` | `0 0 * * *` | Her gün gece yarısı |

**Not:** Hassas bilgiler için **Secret** seçeneğini işaretleyin.

### Adım 7: Deployment

1. **Create Web Service** butonuna tıklayın
2. Render otomatik olarak deployment başlatacaktır
3. **Logs** sekmesinden deployment ilerlemesini takip edin
4. Deployment tamamlandığında service URL'nizi göreceksiniz (örn: `https://hubspot-contact-tagging.onrender.com`)

### Adım 8: Test Etme

1. Web servisinizin URL'sine gidin
2. Sağlık kontrolü yapın: `https://your-service.onrender.com/health`
3. Manuel olarak tetikleyin: 
   ```bash
   curl -X POST https://your-service.onrender.com/trigger
   ```
4. Sonuçları kontrol edin:
   ```bash
   curl https://your-service.onrender.com/status
   ```

## Çalışma Zamanlaması

Varsayılan olarak, uygulama her gün gece yarısı (UTC) otomatik olarak çalışır. Farklı bir zamanlama için:

1. Render dashboard'da service'inizi seçin
2. **Environment** sekmesine gidin
3. `CRON_SCHEDULE` değişkenini güncelleyin

**Örnek Cron İfadeleri:**

- `0 0 * * *` - Her gün gece yarısı (00:00 UTC)
- `0 9 * * *` - Her gün sabah 9:00 (UTC)
- `0 */12 * * *` - Her 12 saatte bir
- `0 0 * * 1` - Her Pazartesi gece yarısı
- `0 14 * * 1-5` - Hafta içi her gün saat 14:00

**Not:** Render ücretsiz planında servisler 15 dakika inaktiflikten sonra uyur. Cron job çalışması servisin uyanmasını sağlar.

## Sorun Giderme

### Service Başlamıyor

1. **Logs** sekmesinde hata mesajlarını kontrol edin
2. Environment variables'ın doğru ayarlandığından emin olun
3. `npm install` komutunun başarılı olduğunu kontrol edin

### HubSpot API Hataları

**401 Unauthorized:**
- Access token'ın geçerli olduğunu kontrol edin
- Token'ın expire olmadığından emin olun

**403 Forbidden:**
- Private app'te gerekli scope'ların verildiğini kontrol edin
- `crm.objects.contacts.read` ve `crm.objects.contacts.write` izinlerini ekleyin

**429 Too Many Requests:**
- HubSpot API rate limit'ine ulaşmışsınız
- Kodu rate limiting için optimize edin veya retry mekanizması ekleyin

### OpenAI API Hataları

**401 Invalid Authentication:**
- API key'in doğru olduğundan emin olun
- Key'in aktif ve geçerli olduğunu kontrol edin

**429 Rate Limit:**
- OpenAI rate limit'ine ulaşmışsınız
- İstekler arasına delay ekleyin (kod içinde 500ms delay var)

**Insufficient Quota:**
- OpenAI hesabınızda yeterli krediniz yok
- Billing bölümünden kredi ekleyin

### Servis Çalışmıyor

1. Manuel tetikleme yapın: `POST /trigger`
2. Logları kontrol edin
3. Her iki API'nin de erişilebilir olduğunu doğrulayın

## Güvenlik Best Practices

1. **API Keys'i Asla Paylaşmayın**
   - Git commit'lere eklemediğinizden emin olun
   - `.env` dosyası `.gitignore`'da

2. **Düzenli Token Rotation**
   - API token'larını 3-6 ayda bir yenileyin
   - Şüpheli aktivite durumunda hemen değiştirin

3. **Rate Limiting**
   - API kullanımınızı izleyin
   - Gereksiz isteklerden kaçının

4. **Monitoring**
   - Düzenli olarak logları kontrol edin
   - Hatalı çalışmaları takip edin
